# Legacy

Esta carpeta recibira codigo inactivo retirado de Ghost Bank Miner.

## Candidatos

- Parser y endpoint dormido `pdf-to-excel`.
- Scripts Python de procesamiento masivo y sus utilidades.
- Cliente JavaScript y estilos duplicados cuando dejen de ser activos.

## Politica

- El codigo activo no puede importar desde esta carpeta.
- Su contenido no forma parte del build ni del despliegue.
- No se corrigen ni amplian funcionalidades archivadas.
- No se guardan PDFs, CSV o TXT reales, credenciales, archivos `.env` ni resultados de usuarios.
- Cada elemento movido debe documentar su entry point anterior y el motivo del archivo.
